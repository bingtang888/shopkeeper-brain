_find_context 方法图解

Markdown 图片上下文提取算法

1. 方法总览

一句话总结

在 Markdown 中找到指定图片所在行，向上找标题和上文，向下找下文，封装成 _ImageContext 返回。

参数

参数类型含义
img_namestr图片文件名
md_contentstrMarkdown 完整内容
img_content_lengthint上下文最大字符数
返回Optional_ImageContext 或 None

调用链

# scan_imgs_dir 对每张图片调用： ctx = self._find_context(img_name, md_content, img_content_length) ├── _find_heading_up() # 向上找最近标题 ├── _extract_limited_context() # 截取上文 ├── _find_heading_down() # 向下找下一个标题 └── _extract_limited_context() # 截取下文

查找 image001.jpg 的上下文：

执行过程
  • 正则匹配：第5行 → md_idx=5
  • _find_heading_up：向上找到第0行 → head="## 万用表外观", prev_index=0
  • 截取上文：md_lines[1:5] → 第1~4行

4. _find_heading_up — 向上找最近标题

def _find_heading_up(self, md_lines, from_idx) -> Tuple[str, int]: for i in range(from_idx - 1, -1, -1): if re.match(r"^#{1,6}\s+", md_lines[i]): return md_lines[i], i return "", -1

从图片行的上一行开始，向上逐行检查是否是标题（以 # 开头）。找到返回标题内容和行号，找不到返回 ("", -1)。

示例

图片在第5行 → 从第4行向上 → 第0行 ## 万用表外观 匹配 → 返回 ("## 万用表外观", 0)

5. _find_heading_down — 向下找下一个标题

def _find_heading_down(self, md_lines, from_idx) -> int: for i in range(from_idx + 1, len(md_lines)): if re.match(r"^#{1,6}\s+", md_lines[i]): return i return len(md_lines)

从图片行的下一行开始，向下逐行检查是否是标题。找到返回行号，找不到返回文档末尾索引。

示例

图片在第5行 → 从第6行向下 → 第10行 ## 测量方法 匹配 → 返回 10

6. _extract_limited_context — 段落化截取

不按字符暴力截取，而是先按段落分组，再按段落选择保留哪些。

段落划分规则

  • 规则1 空行 — 自然段落分隔符
  • 规则2 其他图片行 — ![...](...) 也是分隔符（其他图片不要）

↓

否

direction="front" ?

↓
遍历段落，累加长度
超过限制就停止
↓
direction="front" ?
反转回原始顺序
↓
返回拼接结果

为什么要反转两次？（上文 direction="front"）

  • 第一次反转：上文行是"远→近"，反转后变"近→远"，先遇到离图片最近的段落
  • 累加判断：从最近段落开始累加，超限就停 → 保留离图片最近的内容
  • 第二次反转：恢复原文档顺序，方便 VLM 阅读

段落划分示例

输入
[ "", # 空行→分隔 "万用表是一种常见的电子测量工具。", # 段落1 "它可以测量电压、电流和电阻。", # 段落1 "", # 空行→分隔 "![其他](images/other.jpg)", # 其他图片→分隔 "", # 空行→分隔 "这段文字离图片更远。", # 段落2 ]
划分结果
paragraphs = [ "万用表是一种常见的电子测量工具。\n它可以测量电压、电流和电阻。", "这段文字离图片更远。", ]
长度限制选择（假设 max=30）
  • 段落1 长度=28 → total=28 ≤ 30 → 保留
  • 段落2 长度=10 → total=38 > 30 → 停止

7. 总结

方法职责输入输出
_find_context主方法：找到图片并提取上下文图片名, MD全文, 长度限制_ImageContext 或 None
_find_heading_up向上找最近标题MD行列表, 图片行号(标题内容, 标题行号)
_find_heading_down向下找下一个标题MD行列表, 图片行号标题行号
_extract_limited_context段落化截取并限制长度行列表, 长度限制, 方向截取后的字符串
核心设计思想
  • 标题作为边界：上文从最近标题开始，下文到下一个标题结束，不跨章节
  • 段落化截取：不暴力按字符截断，保留完整段落语义
  • 就近原则：超限时优先保留离图片最近的段落
  • 其他图片排除：上下文中不包含其他图片引用，避免干扰 VLM
